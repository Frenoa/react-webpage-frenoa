# Frenoa

React + TypeScript + Vite 프로젝트입니다.

## 개발 서버 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소로 접속하세요.

## 빌드 및 미리보기

```bash
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다.

## 주요 파일

- `src/App.tsx`: 메인 화면
- `src/index.css`: 전역 스타일
- `src/main.tsx`: 앱 진입점
- `vite.config.ts`: Vite 설정
